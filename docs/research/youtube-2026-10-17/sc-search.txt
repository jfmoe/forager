#### Query Parameters

query

string

required

Search query. For stricter title matching, use YouTube's intitle: operator, for example intitle:"Foursquare Swarm". Quoted queries by themselves may still be broadened by YouTube when no fresh exact matches are available.

uploadDate

string

Upload date

Available options:

`today`,

`this_week`,

`this_month`,

`this_year`

sortBy

string

Sort by

Example:

`relevance`

Available options:

`relevance`,

`popular`

type

string

Type of content to search for

Example:

`videos`

Available options:

`videos`,

`shorts`,

`channels`,

`playlists`

duration

string

Duration of the video. Only applies to videos (not shorts).

Example:

`under_3_min`

Available options:

`under_3_min`,

`between_3_and_20_min`,

`over_20_min`

region

string

2 letter country code of the country to put the proxy in.

Example:

`US`

continuationToken

string

Continuation token to get more videos. Get 'continuationToken' from previous response.

Example:

`4qmFsgKrCBIYVUNkRkpXVWE0M3NtUm00SXBIQnB`

includeExtras

string

`false`
