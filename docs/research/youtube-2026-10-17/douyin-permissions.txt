# 用户类型及权限说明

# [开放平台用户类型 permalink](https://open.douyin.com/platform/resource/docs/accession-guide/type-and-permission\#%E5%BC%80%E6%94%BE%E5%B9%B3%E5%8F%B0%E7%94%A8%E6%88%B7%E7%B1%BB%E5%9E%8B) 开放平台用户类型

开放平台用户在提交机构信息时需要选择用户类型来对其开发者类型进行区分，不同用户类型的开发者将获得差异化的权限列表，可根据创建应用的实际需求申请开通相关权限，自研开发者和系统/线下服务商均可进行企业号认证，企业号不仅可获得更快捷的机构信息审核，并且除获得基础能力权限外，还将获得企业号开发者专属权限（即能力图谱及 Open Api 文档中的“企业号开放能力”）。

可以选择的用户类型有：

- 自研开发者
- 系统服务商

# [用户类型说明 permalink](https://open.douyin.com/platform/resource/docs/accession-guide/type-and-permission\#%E7%94%A8%E6%88%B7%E7%B1%BB%E5%9E%8B%E8%AF%B4%E6%98%8E) 用户类型说明

- 自研开发者

所有注册用户均可选择，审核通过的开发者将获得普通开发者的基础能力权限。

- 系统服务商

系统服务商可以开发第三方应用服务于抖音创作者或商家，或为抖音创作者和商家提供拍摄、创作、代运营等线下服务。审核通过的开发者除获得基础能力权限外，还可获得基于 poi 的商铺、商品库、交易系统等生活服务类开发者专属权限 （即能力图谱及 Open Api 文档中的“生活服务开放能力”）。
